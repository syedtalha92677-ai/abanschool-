# Abn School — WordPress School Management System

A complete school management system built **inside a WordPress theme** — no
separate school plugin, no Elementor, no WooCommerce. Students, fees,
attendance, exams, timetable, homework, staff, ID cards, WhatsApp reminders,
notices, admission inquiries, and parent & student portals are all part of
the theme itself.

## Try it live (no install needed)

Open this link — WordPress Playground boots a full WordPress in your browser
and installs + activates this theme automatically:

https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fsyedtalha92677-ai%2Fabanschool-%2Fmain%2Fblueprint.json

Demo logins (change after install): parent `abn_demo_parent` /
`demo-parent-2026`, student `abn_demo_student` / `demo-student-2026`,
teacher `abn_demo_teacher` / `demo-teacher-2026`.

## Install on your own WordPress

Upload the theme files in this repo as a theme (Appearance → Themes → Add
New → Upload a zip of this folder), or download the ready-made zip from the
project files. Activating the theme runs the one-step setup: pages, roles,
demo data (24 students, 8 staff, fees, attendance, one exam) and portals.

School contacts are placeholders (`[Insert Phone Number]` etc.) — set the
real ones in **Abn School → Settings**. Fee defaults are DEMO values.
